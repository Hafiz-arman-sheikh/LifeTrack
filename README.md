# LifeTrack

LifeTrack is a personal reminder and tracking web app designed to help organize tasks and important dates.

## Features

- Dashboard for reminders and summaries
- Reminder management and categories
- History view
- Light/dark theme control
- Language selection
- Responsive web interface

## Technology

- HTML5 and CSS3
- TypeScript / JavaScript
- Firebase
- Firebase Hosting

## Live demo

https://lifetrack-864d7.web.app/

## Setup

Open the project in your editor and review the Firebase configuration used by the app. Use your own Firebase project configuration when setting up a separate deployment. Never commit private service-account credentials or other server secrets.
